# PowerGenome-tools (redirect)

This repository only exists to redirect traffic from the old
`https://gschivley.github.io/PowerGenome-tools/` GitHub Pages URL to the new
location under the PowerGenome organization:

- **Old:** https://gschivley.github.io/PowerGenome-tools/web/
- **New:** https://powergenome.github.io/PowerGenome-tools/web/

GitHub Pages does not automatically redirect Pages URLs after a repository
transfer, so this minimal repo hosts client-side redirect pages (meta refresh
+ JavaScript, with path preservation). The actual PowerGenome-tools source and
web app live in [PowerGenome/PowerGenome-tools](https://github.com/PowerGenome/PowerGenome-tools).
